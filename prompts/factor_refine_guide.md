## 一、核心体检指标

### 1. IC / Rank IC（预测力）
- |IC| > 0.03 算有效，> 0.05 算优秀
- 优先用 Rank IC（秩相关），对异常值更鲁棒

### 2. IR — 信息比率（稳定性）
- IR = Mean(IC) / Std(IC)
- IR > 0.5 及格，> 1.0 极品
- IC高但IR低 = 有时准有时不准，不可靠

### 3. 分层收益率（单调性）
- 多空收益率（Top-Bottom）要显著为正
- 10组应呈阶梯状单调分布

### 4. 换手率 & IC衰减
- 换手率越低越好
- 高收益+高换手 → 实盘被印花税和滑点吃掉

## 二、病症与优化方向

### 🔴 病症A：IC太低（~0.01）
**诊断**：被噪音/宏观Beta掩盖
**优化方向**：
- 行业+市值中性化
- 非线性变换（取平方、对数、分桶）

### 🟡 病症B：IC尚可但IR低（波动大）
**诊断**：受特定市场风格影响
**优化方向**：
- 剥离合Barra风险（正交化）
- 横截面平滑（MA / EMA）
- 结合宏观状态机

### 🔵 病症C：分层无单调性（中间高两头低）
**诊断**：线性假设失效
**优化方向**：
- 改喂树模型（XGBoost / LightGBM）
- 边缘切断（转为风控过滤因子）

### ⚫ 病症D：收益高但换手极高
**诊断**：微观结构噪音
**优化方向**：
- 拉长计算窗口（3天→10/20天）
- 引入换仓惩罚阈值
- 降级为算法交易执行参考

## 三、深度诊断（进手术室vs火葬场）

### 第一刀：纯度检验（Fama-MacBeth / VIF）
- **可救**：因子与已知风险因子高相关 → 取残差剥离风格，若残差IC显著则救回
- **放弃**：剥离所有风格后IC归零 → 无边际增量，直接放弃

### 第二刀：截面分布诊断（偏度、峰度、散点图）
- **可救**：95%正相关但有5%异常拉平 → 去极值、Rank变换、取对数
- **放弃**：散点图纯随机 → 无效噪音

### 第三刀：逻辑衰退与拥挤度
- **可救**：因子近期失效但核心逻辑未证伪 → 等待反转或加宏观择时
- **放弃**：自相关性高、机构拥挤、IC长期衰减 → Alpha被套利抹平

### 第四刀：宏观环境时变性
- **可救**：整体IC差但在某些宏观环境下IC高 → 变成条件有效因子，加宏观开关
- **放弃**：所有环境下都一样差 → 放弃

### 第五刀：因子构件污染
- **可救**：拆分后发现子构件IC高但被另一个负相关构件拖累 → 重建因子
- **放弃**：最底层构件也无效 → 放弃

### 第六刀：频域与信号噪音比
- **可救**：T+1噪音但T+5到T+20有趋势 → 滤波提取低频趋势 / 延迟建仓
- **放弃**：T+1到T+60无规律横跳 → 白噪音

### 第七刀：孤岛失效与条件触发
- **可救**：在特定子池里有效 → 构建交互因子或条件选股
- **放弃**：任何切片中都无效 → 放弃

### 第八刀：事件时间轴错位
- **可救**：自然日历差但事件对齐后显著 → 改造成脉冲衰减因子
- **放弃**：事件对齐后仍随机分布 → 市场极度有效

## 四、终极心法

> **如果一个坏因子必须经过5道以上工序才能变成正收益——直接放弃。**

"过度折磨数据才招供的，多半是假情报。"

一个真正有经济学逻辑的Alpha，在粗糙分层测试里就能隐约透出单调性的光芒。数学优化应该是"锦上添花"，不是"无中生有"。
